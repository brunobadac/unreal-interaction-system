# Unreal Interaction System

This project is a simple interaction system built in Unreal Engine using Blueprints and basic gameplay logic.

## Features
- Player interaction system
- Door opening system
- Trigger boxes
- Blueprint Interface
- Timeline animation
- Basic interactive environment logic

## How it works
The player can interact with objects by pressing a key. The interaction system communicates through Blueprint Interfaces and triggers events such as opening doors or activating objects.

## Purpose
This project was created to practice Unreal Engine Blueprints, interaction systems, and real-time environment logic.
